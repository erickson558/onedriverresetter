name: comment-code
description: Comenta cada parte del código para explicar qué hace. Úsala tras escribir o modificar cualquier .py.
---

Reglas:
- Cada módulo: docstring con propósito y secciones.
- Cada función/clase: docstring de qué hace, parámetros y retorno.
- Cada bloque no obvio: comentario del *qué y por qué* (no repetir la sintaxis).
- Constantes: comentario de su significado y unidades.
- Idioma de los comentarios: español.
- Nunca dejar código modificado sin comentar.
